IT support document

PC Troubleshooting Checklist

A step-by-step guide for a computer that will not work properly, written for non-technical users.

  • Documentation
  • Troubleshooting
Read the checklist
  1. Check that the power cable and outlet are working.
  2. Restart the computer.
  3. Check the monitor cable and brightness.
  4. Check free disk space and remove files you no longer need.
  5. Install pending system and driver updates.
  6. Run a malware scan.
  7. Test memory and storage with the built-in Windows tools.
  8. If the problem continues, write down what you tried and ask a supervisor for help.
